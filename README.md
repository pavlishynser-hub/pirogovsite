# MAXTRAVEL - Premium European Transfers

A modern, responsive website for MAXTRAVEL - a passenger transportation company specializing in minibus transfers across Europe.

## 🚐 Features

- **Bilingual Support**: English & Czech language switcher with persistent preference
- **Techno Premium Design**: Dark theme with orange accents, modern typography
- **Fully Responsive**: Mobile-first approach, works on all devices
- **Smooth Animations**: Scroll-triggered animations, hover effects
- **Contact Options**: Multiple contact methods including WhatsApp, Telegram, phone, email
- **SEO Optimized**: Meta tags, semantic HTML structure

## 📁 Project Structure

```
piroovsite/
├── index.html      # Main HTML structure
├── styles.css      # All styling (CSS custom properties, responsive)
├── script.js       # Language switcher, animations, form handling
└── README.md       # This file
```

## 🎨 Design Features

- **Color Palette**: Dark backgrounds (#0a0a0f, #12121a) with orange accents (#ff6b2c)
- **Typography**: Orbitron (display) + Rajdhani (body) from Google Fonts
- **Sections**: Hero, About, Services, Fleet, Routes, Reviews, Contact, Footer
